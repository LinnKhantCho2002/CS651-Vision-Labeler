# CS651: Vision Labeler

This project demonstrates a web upload interface backed by Google Cloud Vision label detection, with Google App Engine standard as its deployment target.

**Current status:** deployed to App Engine and verified with real Google Cloud Vision on 2026-11-10. Two synthetic images produced distinct real labels. The source repository is private. Wiki publication, group/reviewer access and screenshots remain unfinished. Offline demo mode uses clearly marked fixtures.
