# CS651: Vision Labeler

This project demonstrates a web upload interface backed by Google Cloud Vision label detection, deployed to Google App Engine standard.

**Current status:** deployed and verified with real Google Cloud Vision on 2026-11-10. Two synthetic images produced distinct real labels. The source repository and this wiki are public. Group details, collaborator write access, browser screenshots and Canvas submission remain unfinished. Offline demo mode uses clearly marked fixtures.
